# columns-chapter

Custom **columns** block. Purpose: Narrative chapter: narrow chapter-label column beside a statement heading, image and annotation.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells: cell 1 = chapter label + short tagline; cell 2 = H2 statement, image, annotation paragraphs.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
