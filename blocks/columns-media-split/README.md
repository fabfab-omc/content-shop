# columns-media-split

Custom **columns** block. Purpose: 50/50 text-and-image split; text column with label, heading and body beside an image with caption.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells: cell 1 = label, H2, body, sign-off paragraph; cell 2 = image + caption paragraph.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
