# cards-campaigns

Custom **cards** block. Purpose: Grid of campaign cards: key visual + campaign name + 'View campaign' link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per campaign; cell 1 = key visual image (may be empty), cell 2 = richtext (h3 campaign name + p>a 'View campaign →').

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
