# cards-features

Custom **cards** block. Purpose: Grid of feature tiles (metric/number paragraph, H3 title, description); image cell may be left empty.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile (6 on source); cell 1 = image (optional, may be empty), cell 2 = metric/number paragraph, H3 title, description.

## Supported variations

No variations.
