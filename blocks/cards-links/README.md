# cards-links

Custom **cards** block. Purpose: Onward/support link tiles: optional icon, bold title, short muted description, CTA with circled arrow.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile; cell 1 = icon image (may be empty), cell 2 = richtext (h3 title + p description + p>a CTA).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
